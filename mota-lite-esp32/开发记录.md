## 1. 硬件档案（全部实测，非查资料）

### 1.1 板载资源

| 器件 | 型号 | 接口 | 备注 |
|---|---|---|---|
| SoC | ESP32-S3R8 | — | 叠封 8 MB PSRAM |
| Flash | 16 MB NOR | QIO 80 MHz | — |
| 屏 | CO5300 | QSPI | 480×480，无背光（AMOLED 自发光，亮度走命令 0x51） |
| 触摸 | CST9220 | I2C 0x5A | 驱动用 `waveshare/esp_lcd_touch_cst9217` |
| 电源 | AXP2101 | I2C 0x34 | DCDC1=VCC3V3，ALDO1=A3V3（麦克风） |
| IMU | QMI8658 | I2C 0x6B | 六轴，INT 接 GPIO17/21 |
| RTC | PCF85063 | I2C 0x51 | 中断 GPIO13 |
| 音频 | ES8311（DAC）+ ES7210（ADC） | I2S + I2C 0x30/0x80 | 双麦 + 回声消除 + 功放 |
| microSD | — | **SDMMC 1-bit** | CLK2/CMD1/D0 3（BSP 用 SDMMC，非 SPI） |

### 1.2 引脚（来自官方 BSP yaml，勿随意改）

| 用途 | 引脚 |
|---|---|
| I2C 总线 | SDA **15** / SCL **14**，400 kHz |
| 屏 QSPI | MOSI **4** / MISO **5** / WP **6** / HD **7** / SCLK **38** / CS **12** / RST **39** |
| 触摸 | RST **40** / INT **11**，**swap_xy=1 + mirror_y=1**（关键，否则方向颠倒） |
| 功放使能 | **46**（PA_CTRL） |
| 用户键 Key3 | **18**（上拉，按下接地） |
| I2S | MCLK 42 / BCLK 9 / LRCK 45 / DOUT 8 / DIN 10 |

### 1.3 出厂固件的分区表（重要参照）

```
nvsfactory  0x009000 / 0x032000
nvs         0x03B000 / 0x0D2000    ← WiFi 密码 + 小智设备身份
otadata     0x10D000 / 0x002000
phy_init    0x10F000 / 0x001000
model       0x110000 / 0x0F0000
factory     0x200000 / 0x800000    ← 8 MB 固件本体
storage     0xA00000 / 0x600000    ← 6 MB 字体/图片资源
```

现在用的是自己的分区表（`partitions.csv`）：nvs 0x9000/0x6000，phy_init 0xf000/0x1000，factory 0x10000/**0x700000**。

## 4. 新电脑环境搭建

### 4.1 前提

- **Windows**（Linux/macOS 也可以，但 `build.ps1` 要改写）
- **PowerShell**，不要用 Git Bash 跑 IDF 命令（会被拒绝：`MSys/Mingw is not supported`）
- Python 3.9+（实测 3.13 可用）
- 磁盘 ≥ 6 GB（IDF 源码 1.5 GB + 工具链 2 GB + 构建产物）

### 4.2 装 ESP-IDF v6.0.2

```powershell
mkdir C:\esp; cd C:\esp
git clone --depth 1 -b v6.0.2 https://github.com/espressif/esp-idf.git esp-idf
cd esp-idf
```

国内网络慢就加镜像（乐鑫官方 CDN）：

```powershell
$env:IDF_GITHUB_ASSETS="dl.espressif.cn/github_assets"
```

装工具链与 Python 环境（**必须在 PowerShell / cmd 里**）：

```powershell
python tools\idf_tools.py --non-interactive install --targets=esp32s3
python tools\idf_tools.py --non-interactive install-python-env
```

> `install-python-env` 若失败在 `setuptools` 版本冲突，别用清华源，直接走官方 PyPI（必要时设 `$env:HTTP_PROXY`）。

### 4.3 拿到工程

```powershell
git clone git@github.com:FDavis348915654/mota-lite.git C:\VersionFiles\mota-lite
```

- 仓库：`git@github.com:FDavis348915654/mota-lite.git`（SSH，用 Deploy key `~/.ssh/mota_lite_deploy_key`，`~/.ssh/config` 里配 `IdentitiesOnly yes`）
- `mota-lite-esp32/` 的 `.gitignore` 已排除 `build/`、`managed_components/`、`sdkconfig`、`dependencies.lock`，所以仓库里只有源码，体积很小
- 工程依赖同级的 `../mota-lite-web/`（读 `logic.js`、`tables.js`、`assets/`），所以**整个仓库一起 clone**，不要只拷 esp32 子目录

### 4.4 首次构建

```powershell
cd C:\VersionFiles\mota-lite\mota-lite-esp32
.\build.ps1 set-target esp32s3     # 首次，会下载 6 个组件
.\build.ps1 build
```

`build.ps1` 里写死的东西（**新机器路径不同要改**）：

| 变量 | 原机器值 | 说明 |
|---|---|---|
| `$IdfRoot` | `C:\esp\esp-idf` | IDF 源码 |
| `$PyEnv` | `%USERPROFILE%\.espressif\python_env\idf6.0_py3.13_env` | 目录名随 Python 版本变 |
| `$Tools` | `%USERPROFILE%\.espressif\tools` | 工具链 |
| `$env:ESP_IDF_VERSION` | `"6.0.2"` | **不能带 `v` 前缀**，semver 解析会报错 |

工具链目录名（`xtensa-esp-elf\esp-15.2.0_20251204`）也写在 PATH 拼接里，装完后 `ls %USERPROFILE%\.espressif\tools\xtensa-esp-elf` 核对一下。

### 4.5 烧录与验证

### 4.6 故障对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| `MSys/Mingw is not supported` | 在 Git Bash 里跑 IDF | 换 PowerShell |
| `Version string lacks a numerical component` | `ESP_IDF_VERSION` 带了 `v` | 改成 `6.0.2` |
| 配置「莫名失败」但无明显错误 | PowerShell `$ErrorActionPreference="Stop"` 把 Kconfig 警告当致命错 | 保持 `Continue` |
| `Cannot load build/project_description.json` | 上次配置没跑完 | 删 `build\` 重来 |
| 组件下载卡在某一个 | 网络 | 重跑 `set-target`，或单独 `idf.py add-dependency` |
| `Failed to allocate priv TX buffer` | 整屏一次性推，DMA 中转缓冲分配不到 | 已改分块 20 行，勿改回整屏 |
| 屏幕偏紫粉 | RGB565 高低字节没交换 | 检查 `gfx.h` 的 `rgb565_pack` 与 `export_assets.py` 的 `rgb565` 是否都做了交换 |
| 画面多转 90° | CO5300 原生扫描方向 | `board_flush` 里已做逆时针转置 |
| 触摸方向反 | `swap_xy` / `mirror_y` | 见 `board.c` 的 `touch_init`，官方值是 `swap_xy=1, mirror_y=1` |
| 烧录失败 / 端口占位 | 串口被 monitor 占用 | 关掉监视器再烧；必要时按住 BOOT 再上电 |

## 6. 调研结论（避免重复踩）

这些是这次查证过的，下次不用再查：

| 问题 | 结论 |
|---|---|
| 能接舵机/传感器吗 | **不能**。40 个 GPIO 全被板载外设占用，无引出排针 |
| TF 卡能放程序跑吗 | **不能**。ESP32-S3 是 XIP 架构，代码必须在内置 Flash 的映射地址空间，TF 卡是块设备 |
| TF 卡最大容量 | 实用 **32 GB / FAT32**。驱动支持 SDXC，但 ESP-IDF 的 FatFs 不认 exFAT，64 GB 卡默认 exFAT 挂不上 |
| 出厂固件能改吗 | **不能**。仓库只有 bin，README 明写 `source and build instructions are not included` |
| 小智怎么绑定 | 设备显示/播报 6 位码 → xiaozhi.me 控制台 → 新建智能体 → 添加设备 → 输入码 → 选「开源版」 |
| 小智绑定的设备身份在哪 | NVS（`Client-Id` UUID），全片擦除就没了 |
| 官方 BSP 值不值得用 | 不值得。硬拉 lvgl+libpng+freetype+jpeg+qoi+zlib（23 个组件），自绘 framebuffer 用不到 |
| 逻辑层怎么复用 | QuickJS（`espressif/quickjs-ng` 0.14.0，官方组件，IDF ≥5.4） |
| 中文字号 | **24 px**。16 px 复杂汉字糊成一团（「魔」的鬼部无法分辨） |
| AMOLED 烧屏 | 长期静态 UI 会留残影，做常亮设备需像素偏移/亮度衰减 |

### 10.1 这一版做了什么

| 模块 | 实现 |

### 11.7 熄屏（02:2x 追加）

Davis 要求「开发全部完成后把开发板关掉，不能整夜亮屏」。为此加了熄屏能力：

| 项 | 实现 |
|---|---|
| 关屏 | `board_screen(false)`：`esp_lcd_panel_co5300_set_brightness(0)` + `DISPOFF(0x28)` |

## 12. 小屏适配：卷轴相机 + 点击反馈（05:0x–06:0x）

Davis 反馈：设置按钮难点、希望有触摸圆圈、地图要卷轴滚动并放大、侧栏与底栏要更大。

### 12.1 「设置难点」的真实原因（实测，不是猜）

用串口注入点击并读 `state`：

| 点击位置 | 结果 |
|---|---|
| `(450,333)` | 覆盖仍为 0 —— 命中「图鉴」，而图鉴无书时**静默无反应** |
| `(450,367)` | 覆盖 = 5（设置打开） |

结论：按钮当时是 **52×30 px**（约 5.9×3.4mm，远小于指尖），
而且 **位置随可见动作数量浮动**（4~7 个 → y 在 284~382 之间跳），
相邻间隙只有 4px、右边距 4px；失败时既无按下态也无提示，所以主观上就是"难点"。

### 12.2 新布局

| 项 | 旧 | 新 |
|---|---|---|
| 格子 | 28px（整层 13×15 全显示） | **42px**（7×9 视口 + 相机） |
| 侧栏 | 116px，数值 20px | **186px**，数值 24px |
| 按钮 | 52×30，2 列 | **86×52**，2 列；设置独占整行 178×52 |
| 底栏 | 60px，2 行 | **102px，3 行**（长消息不再截断） |
| 顶栏 | 楼层 + 步数（20px，缺「步」字） | 楼层 + 步数（24px） |

- 相机与 web 同构：`camX = clamp(x - floor(cols/2))`，**整格对齐、直接跳**，不做插值。
  实测 1F 连续右移：cam 84 → 126 → 168，每步正好 +42（=一格）。
  换层/读档/新局由 `s_cam_floor == -1` 触发同一路径。
- 精灵放大：`gfx_sprite_scaled()` 最近邻把 28px 源帧画成 42px（1.5 倍），源图集不改。
- 点格子：`(屏幕坐标 + 相机偏移) / 42` 换算成全图坐标，BFS 与交互逻辑未改。

### 12.3 点击反馈（对齐 web 的 `:active`）

| 反馈 | 实现 |
|---|---|
| 按钮按下 | 手指压住时就亮（`btn_hot()` 用当前按下点判断），抬手后再保持 260ms |
| 覆盖范围 | 侧栏 7 个动作、剧情「继续」、商店/法师每一行与「离开」、设置三行与「关闭」、确认弹层两按钮 |
| 选中格 | 2px 亮框 + 四角加粗标记，保留到下一次操作或换层 |
| 唤醒 | 熄屏后第一下只点亮，抬起也不触发操作 |
| 输入语义 | 按下只记录起点，**抬起且位移 ≤16px 才判定为点击**（对齐 web 的 pointerdown/click） |

> 最初做的"触摸圆圈 1 秒淡出"已按 Davis 要求移除（对应实现 `gfx_ring_fade()` 已一并删除，避免留死代码）。
> 现在"点没点上"靠三件事表达：按住高亮、点击后 260ms 残留、选中格亮框。

### 12.4 圆角屏遮挡（按实机照片校正）

Davis 拍了实机照片，暴露两件事：

1. `血 1222`、`红 3` 这类**右对齐数值**一直画到 x=476（离边 4px），被圆角切掉；
   只把「步数」内收是不够的。
2. 地图四角被面板圆角**硬切**，看起来像"缺一块"。

改法两层：

- 内容右边界统一收到 `HUD_R = SCR_W - 26 = 454`，HUD 列宽/按钮宽度都由它推导；
- 渲染最后一步 `gfx_mask_rounded(46)`，把四角圆弧外涂纯黑。AMOLED 黑色即熄灭，
  视觉上等于"圆角窗口"，不再有被切的碎片。半径 46px 是按 480 宽反推的实际圆角。

> 教训：圆角屏不能只靠"文字起点留白"，**右对齐的数值才是最容易贴边被切的**。
