# mota-lite · 腕上魔塔

经典魔塔（Dungeon RPG）复刻 Lite：**21 层 × 13×15 大地图、窄走廊 + 瓶颈守路（横贯闸墙只留一格缺口、缺口站守路怪）、支路凹室资源把守、怪数与难度提高（常规怪 9→12 / 全塔损血上调约 30%）、9 种怪物（含强度超前 9 层的「宝库守卫」）、暗门 / 铁门 / 三色钥匙经济、打怪经验与法师兑换、盗贼任务线与 16F 封印门、炸弹中后期解锁、图鉴 / 飞行器 / 商店、1F 塔灵小精灵 + 13F 能量核心 + 17F 起能量护盾主线、交互等待一拍、怪物防御体系重构（怪防按 0.65×玩家实测攻击 / 5 回合战斗 / 2F~16F 石头人高防低攻挡路 / 破防临界决策）**。
纯静态前端，零构建、零外部素材依赖 —— 像素图集由 Python 脚本程序化生成，音效为 8-bit WAV。

> A lightweight remake of the classic Magic Tower (魔塔) dungeon RPG. All art is procedurally generated and SFX are tiny 8-bit WAVs — no binary asset packs, no build step.

**运行方式**：本地起静态服务即可玩（ES Module 需要 http 协议，不能直接双击 `index.html`），见下方「快速开始」。

## 快速开始

逻辑层用了 ES Module（`import ... from './logic.js'`），`file://` 直接打开会被浏览器拦截，起个静态服务即可：

```
cd mota-lite-web
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

页面内置 212×520 手环屏模拟器（右侧是调试工作台），桌面 / 手机浏览器都能玩；存档存 `localStorage`，关掉再开自动续玩。

## 操作

| 动作 | 触屏 / 鼠标 | 键盘 |
|---|---|---|
| 移动 | **点击格子**（自动寻路，实体格为阻挡） | `WASD` / 方向键 |
| 交互（怪物 / 道具 / NPC / 门） | 点击实体本身，「撞一下停原地」，再走一步进入；从远处走过去会先在旁边**等一拍**（150ms，等于移动一格）才结算，本来就相邻则点击立即交互 | 走到相邻格后朝它移动 |
| 飞行器 升层 / 降层 | 屏幕内 `升层` / `降层` 按钮（只能去已探索楼层） | `F` 升层 / `Shift+F` 降层 |
| 引爆炸弹 | 屏幕内 `炸弹` 按钮 | `B` |
| 怪物图鉴 | 屏幕内 `图鉴` 按钮（需先拾取图鉴） | `C` |
| 新游戏 / 设置 / 商店 | 屏幕内对应按钮（危险操作有二次确认） | `R` 新游戏 |
| 回放 播放 / 步进 / 调速 | 右侧工作台回放条 | `空格` 播放、`[` `]` 步进、`+` `-` 调速、`Esc` 退出 |
| 弹层确认 / 关闭 | 点击按钮 | `Enter` / `空格` 确认、`Esc` 关闭 |

> `炸弹` / `购买` 按钮开局隐藏：分别由「救出 12F 老者」「首次走到商店格旁交互」解锁；`购买` 解锁后可随时随地打开商店。常驻交易弹层（商店 / 法师兑换）没有「继续」按钮，购买后不关闭，点「离开」才关；其正文区高度固定，文字只在框内滚动，不会因打字机把商品按钮推走导致误选。

## 玩法要素

- **门与钥匙经济**：黄 / 蓝 / 红门封住唯一入口，消耗对应钥匙；**铁门 `G`**（7F / 14F / 21F 主路）一次耗 3 把黄钥匙；商店第四项 20G 买 1 把黄钥匙，配合地图投放、暗门奖励、盗贼救援构成攒 / 花 / 买闭环。开门后停在原地，再走一步才进原门格。
- **暗门 `A`**：伪装成普通砖墙（色块与精灵完全一致），主动撞墙才显形，墙后有钥匙 / 药水 / 金币与三处宝石彩蛋。地图上的炸弹拾取格已全部移除。
- **封印门 `Z`**：16F 上楼唯一入口，三色钥匙都打不开，只有完成盗贼任务线才能撬开；不开就走不到后续楼层，点击寻路两种模式都不可穿越。
- **经验与法师兑换**：打怪同时获得金币与经验，`monsterExp = 基础 exp × (楼层档+1)`（1~7F×1 / 8~14F×2 / 15~21F×3，全塔约 905 EXP）；8F 救出法师后常驻，用 `30 EXP` 换 `+3攻 / +3防 / +100HP`。
- **盗贼任务线**：15F 救出盗贼 → 13F 取锁匠工具 `j` 交他（远程开 16F 封印门）→ 19F 取钱袋 `q` 交他 → 盗贼给谢礼后离塔。法师 / 盗贼救出后都成为可反复对话的常驻格。
- **炸弹中后期化**：12F 房间救出老者 `E` 后解锁炸弹能力并赠 1 枚，之后商店第 5 项才可买（30G）；此前炸弹按钮隐藏、商店无此项。
- **强敌宝库（v0.14）**：地图用隔间墙分出走廊与死胡同，怪物和道具都更密（空地占比 57.5%→44.4%）；**3F / 9F / 14F / 18F** 各有一间墙围石室，唯一入口由「宝库守卫 `X`」把守。它按 `FLOOR_SCALE[floor+9]` 取超前 9 层强度，首次进层必定「破不了防 / 会阵亡」，撞上去会被拦住并弹一次「暂不可敌」引导，不白送命。纯支线不挡主路 —— 先往上闯攒够攻防 / 经验再回来打，打赢后清成地板才能进去取铁剑 `s` 与铁盾 `S`；终局裸属性回头四只全部可打。
- **关卡节奏（v0.15）**：地图由**横贯闸墙**切成数条窄走廊带，每道墙只留一格缺口、缺口上站着「守路怪」——不打掉就到不了下一带、更上不了楼；**1F~21F 全部「不打怪不能上楼」**，全塔 38 道闸墙缺口都是图论割点、77 只几何必打怪。支路凹室三面砌墙、入口也有守护怪，里面的宝石 / 血瓶 / 金币要清掉它才拿得到；第一带固定投放成长道具与三色钥匙，保证开局先捡补给再清怪。正常节奏是**杀完一层的怪、整理好补给再进下一层**，而不是直冲楼梯。怪数 5~6→9，但 21 层 `targetLoss` 与 v0.14 逐层完全一致，只是战斗场次变多、每场更轻；强敌宝库仍是纯支线（不挡上楼）。空地占比 44.4%→**40.0%**（21F 61%→36%）。
- **小精灵 / 能量核心 / 能量护盾（v0.16）**：**1F** 出生点正下方 `(1,2)` 站着常驻「塔灵小精灵 `e`」，走到旁边交互可听塔的背景故事；**13F** treasure 房放全塔唯一的「能量核心 `C`」，与盗贼任务的硬门槛「锁匠工具 `j`」同房，玩家不可能漏拿。**17F 起常规怪数值上台阶**（`hp×1.1 / 攻×1.05 / 防×1.0`，v0.17 收敛；精英 `X` 与魔王不叠加），且**没带核心回 1F 找小精灵强化前，怪物身上的「能量护盾」会让 `calcBattle()` 直接判失败**——商店买攻防、法师兑经验堆到 99999 也绕不过，必须回去做主线，否则一定卡在 17F 过不去。强化一次性给 `攻+80 / 防+60 / 生命+1200`，护盾随之消散；小精灵三态（讲背景 / 持核心强化 / 已强化闲聊），攻略回放会真实走出「17F 卡关 → 逐层下楼回 1F 强化 → 再上楼」的往返。怪数 **9→12**、`targetLoss` 全塔上调约 **30%**（24/26…72 → 31/34…94），难度整体提高；四处强敌宝库与魔王同步校准（魔王 `ATK 300→380`）。能量核心与小精灵**不是可选捷径，是必做主线**。
- **交互等待（v0.16）**：点击远处实体时，自动寻路走到实体相邻格后不再同拍立即结算，而是**等一拍 `AUTO_STEP_MS=150`**（与自动行走移动一格同源）再交互，能看见英雄先在旁边站稳；本来就停在旁边的点击走 `walkTo()` 相邻分支仍**立即交互**。剧情打断 / 重开 / 改点别的格子由 `stopAuto()` 统一取消残留延迟。
- **怪物防御体系 / 高防低攻挡路怪（v0.17）**：用户反馈「怪防太低没有挑战性，原版魔塔怪防常接近攻击力，有些怪甚至防御超高、攻击较低，用来挡住玩家前进」。字面「怪防≈怪攻」经离线模拟会 21 层全部破不了防（怪攻本就按玩家 DEF 建模、必然大于玩家攻），故按「**怪防 = 0.65 × 每层首次战斗实测玩家攻击**」建模：每击伤害变薄、战斗从 3 回合拉到 **5 回合**，1F 裸装连史莱姆都破不了防，必须先捡第一带铁剑 / 红宝石垫攻击再回头清怪；图鉴「临界攻击」给出少挨一回合的攻击阈值。全塔总损血较 v0.16 再 **+26%**（6558→8240）。另在 **2F~16F** 每层第一道闸墙缺口与第一个凹室入口复用「石头人 `m6`」摆出 `hpW1.0 / atkW0.92 / defW1.23` 的**高防低攻挡路怪**（防 ≈ 0.80×玩家攻击、每击只剩 0.20×攻击、约 7~8 回合，攻击低但砍不动），全塔 40 只、其中 20 只落在主路真割点；1F 与 17F 起不投放，避免裸属性 / 屏障倍率叠加成死局。逻辑层 / 存档 / 交互 / 精灵主线零改动，纯配置层数值。
- **战斗公式**：经典先手制，`回合数 = ceil(敌HP / (我攻-敌防))`，承受 `回合数-1` 次反击；法师系 `pierce` 无视防御；怪物手册给出「临界攻击」与「每 +1 防少掉多少 HP」。
- **逐层数值曲线（v0.17 重构）**：每层独立 `FLOOR_SCALE`（21 组逐层 + 9 组线性外推，共 30 组），由 `make_levels.py` 按「每层首次战斗实测 ATK/DEF」反解 —— **怪防 = 0.65 × 实测玩家攻击**、战斗拉长到 **5 回合**、每怪损血按 `costMul=5.0` 标定后再 ×1.3；逐层怪 ATK 单调爬坡，17F 起再叠屏障倍率（v0.17 收敛为 `hp×1.1 / 攻×1.05 / 防×1.0`），保证 21/21 层都有掉血压力。**怪防不再是攻击力的零头**：1F 裸装连史莱姆都破不了防，必须先捡第一带的铁剑 / 红宝石把攻击垫过破防临界；图鉴「临界攻击」会告诉还要堆多少攻才能少挨一回合。外推段专供强敌 `scaleShift` 取「超前层」数值，不会退化成当层就能打。
- **收集**：三色钥匙、血瓶、宝石、飞行器、炸弹、怪物图鉴（含每层清剿标注）、NPC 房间事件。

## 开发

```
cd mota-lite-web

python3 tools/make_levels.py        # 重新生成 levels/levels.json（改关卡后跑）
python3 tools/build_tables.py       # levels.json -> tables.js；--check 只校验一致性
python3 tools/gen_assets.py         # 重新生成图集 / 音频 / manifest.json（改美术后跑）

node tools/validate_version.mjs     # 版本 / 布局 / 字号 / 静态防漂移断言（120 项）
node tools/validate_levels.mjs      # 关卡语义断言（111 项）
node tools/validate_logic.mjs       # 逻辑层断言（460 项）
node tools/validate_assets.mjs      # 资源断言（99 项）
node tools/browser_check.mjs        # 真实 Chromium 回归（383 项，需先起 http.server 8765）
```

全套合计 **1173 项断言**（离线四套 790 + 真实浏览器回归 383）。

改完**必须递增版本号**，否则标题 / 页脚 / 版本记录会漂移：

1. `mota-lite-web/version.js` 的 `VERSION`（唯一真源，HTML 不硬编码任何版本号）
2. 同文件 `CHANGELOG` 最前面补一条，`v` 必须与 `VERSION` 完全一致

> `assets/manifest.json` 的 `version` 由 `tools/gen_assets.py` 从 `version.js` 读取并写入，升级版本后重跑该脚本即可（精灵内容确定时二进制不变）。

### 协作流程

> 完整的协作与开发约定（沟通、方案确认、版本与生成链、测试分级、备份口令、工程边界）见 **[开发注意事项.md](开发注意事项.md)**；本段只列速查项。

这个目录同时是云电脑上的工作副本，**动手前先同步远端**。仓库已配置 `pull.rebase=true` 与 `rebase.autoStash=true`，有未提交改动时也能直接拉：

```
git pull --rebase        # 或简写 git sync（已设别名）
```

日常顺序：

1. `git pull --rebase` 拉到最新
2. 改 `mota-lite-web/` 下的代码，递增 `version.js`
3. 按《开发注意事项》第 4 节做**对应量级**的校验：日常小改动只做轻量校验（语法检查 + 改动点定向验证），大功能更新或用户明确说「完整测试」才跑离线四套 + `node tools/browser_check.mjs`
4. **只有用户明确说「备份」才执行 `git add -A && git commit -m "..." && git push`**。日常代码改动、版本递增、文档更新都只留在本地，不用每次对话之后都提交；备份前默认也只做轻量校验。

### 版本控制约定

`.gitignore` 只排除「能重新生成或与运行无关」的东西，工程本身（含图集、音频、文档、截图）全部入库：

| 排除项 | 原因 |
|---|---|
| `node_modules/`、`__pycache__/`、`*.pyc` | 依赖与 Python 运行缓存 |
| `mota-lite/dist/`、`dist/` | 快应用构建产物，可重新打出 |
| `.codebuddy/`、`.cloudstudio` | 云开发平台目录 |
| `.vscode/`、`.idea/`、`.DS_Store`、`Thumbs.db` | 编辑器与系统文件 |
| `*.log` | 临时日志 |

`mota-lite-web/tools/_bak/`（v7 / v11 / v12 / v13 的关卡与 tables 备份）**保留在仓库里**：它们是回归对照与回滚依据。
