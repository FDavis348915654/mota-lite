# mota-lite · 腕上魔塔

经典魔塔（Dungeon RPG）复刻 Lite：**21 层 × 13×15 大地图、窄走廊 + 瓶颈守路（横贯闸墙只留一格缺口、缺口站守路怪）、支路凹室资源把守、怪数与难度提高（常规怪 9→12 / 全塔损血上调约 30%）、9 种怪物（含强度超前 9 层的「宝库守卫」）、暗门 / 铁门 / 三色钥匙经济、打怪经验与法师兑换、盗贼任务线与 16F 封印门、炸弹中后期解锁、图鉴 / 飞行器 / 商店、1F 塔灵小精灵 + 13F 能量核心 + 17F 起能量护盾主线、交互等待一拍、怪物防御体系重构（怪防按 0.65×玩家实测攻击 / 5 回合战斗 / 2F~16F 石头人高防低攻挡路 / 破防临界决策）+ 任务顺序重排 / 软门槛 / 百分比灌顶 / 任务关联剧情链（v0.18）+ 攻击吸血怪「噬血蝠」/ 前期打不过后期回头打 / 守门怪大幅强化 / 难度提高（v0.19）+ 前期防杀抑制 / 难度曲线再次调高 / 合理利用金币经验才能通关（v0.20）**。
纯静态前端，零构建、零外部素材依赖 —— 像素图集由 Python 脚本程序化生成，音效为 8-bit WAV。

> A lightweight remake of the classic Magic Tower (魔塔) dungeon RPG. All art is procedurally generated and SFX are tiny 8-bit WAVs — no binary asset packs, no build step.

**运行方式**：本地起静态服务即可玩（ES Module 需要 http 协议，不能直接双击 `index.html`），见下方「快速开始」。

## 快速开始

逻辑层用了 ES Module（`import ... from './logic.js'`），`file://` 直接打开会被浏览器拦截，起个静态服务即可：

```
cd mota-lite-web
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

页面内置 212×520 手环屏模拟器（右侧是调试工作台），桌面 / 手机浏览器都能玩；存档存 `localStorage`，关掉再开自动续玩。

## 操作

| 动作 | 触屏 / 鼠标 | 键盘 |
|---|---|---|
| 移动 | **点击格子**（自动寻路，实体格为阻挡） | `WASD` / 方向键 |
| 交互（怪物 / 道具 / NPC / 门） | 点击实体本身，「撞一下停原地」，再走一步进入；从远处走过去会先在旁边**等一拍**（150ms，等于移动一格）才结算，本来就相邻则点击立即交互 | 走到相邻格后朝它移动 |
| 飞行器 升层 / 降层 | 屏幕内 `升层` / `降层` 按钮（只能去已探索楼层） | `F` 升层 / `Shift+F` 降层 |
| 引爆炸弹 | 屏幕内 `炸弹` 按钮 | `B` |
| 怪物图鉴 | 屏幕内 `图鉴` 按钮（需先拾取图鉴） | `C` |
| 新游戏 / 设置 / 商店 | 屏幕内对应按钮（危险操作有二次确认） | `R` 新游戏 |
| 回放 播放 / 步进 / 调速 | 右侧工作台回放条 | `空格` 播放、`[` `]` 步进、`+` `-` 调速、`Esc` 退出 |
| 弹层确认 / 关闭 | 点击按钮 | `Enter` / `空格` 确认、`Esc` 关闭 |

> `炸弹` / `购买` 按钮开局隐藏：分别由「救出 12F 老者」「首次走到商店格旁交互」解锁；`购买` 解锁后可随时随地打开商店。常驻交易弹层（商店 / 法师兑换）没有「继续」按钮，购买后不关闭，点「离开」才关；其正文区高度固定，文字只在框内滚动，不会因打字机把商品按钮推走导致误选。

## 玩法要素

- **门与钥匙经济**：黄 / 蓝 / 红门封住唯一入口，消耗对应钥匙；**铁门 `G`**（7F / 14F / 21F 主路）一次耗 3 把黄钥匙；商店第四项 20G 买 1 把黄钥匙，配合地图投放、暗门奖励、盗贼救援构成攒 / 花 / 买闭环。开门后停在原地，再走一步才进原门格。
- **暗门 `A`**：伪装成普通砖墙（色块与精灵完全一致），主动撞墙才显形，墙后有钥匙 / 药水 / 金币与三处宝石彩蛋。地图上的炸弹拾取格已全部移除。
- **封印门 `Z`**：16F 上楼唯一入口，三色钥匙都打不开，只有完成盗贼任务线才能撬开；不开就走不到后续楼层，点击寻路两种模式都不可穿越。
- **经验与法师兑换**：打怪同时获得金币与经验，`monsterExp = 基础 exp × (楼层档+1)`（1~7F×1 / 8~14F×2 / 15~21F×3，全塔约 905 EXP）；8F 救出法师后常驻，用 `30 EXP` 换 `+3攻 / +3防 / +100HP`。
- **盗贼任务线**：15F 救出盗贼 → 13F 取锁匠工具 `j` 交他（远程开 16F 封印门）→ 19F 取钱袋 `q` 交他 → 盗贼给谢礼后离塔。法师 / 盗贼救出后都成为可反复对话的常驻格。
- **炸弹中后期化**：12F 房间救出老者 `E` 后解锁炸弹能力并赠 1 枚，之后商店第 5 项才可买（30G）；此前炸弹按钮隐藏、商店无此项。
- **强敌宝库（v0.14）**：地图用隔间墙分出走廊与死胡同，怪物和道具都更密（空地占比 57.5%→44.4%）；**3F / 9F / 14F / 18F** 各有一间墙围石室，唯一入口由「宝库守卫 `X`」把守。它按 `FLOOR_SCALE[floor+9]` 取超前 9 层强度，首次进层必定「破不了防 / 会阵亡」，撞上去会被拦住并弹一次「暂不可敌」引导，不白送命。纯支线不挡主路 —— 先往上闯攒够攻防 / 经验再回来打，打赢后清成地板才能进去取铁剑 `s` 与铁盾 `S`；终局裸属性回头四只全部可打。
- **关卡节奏（v0.15）**：地图由**横贯闸墙**切成数条窄走廊带，每道墙只留一格缺口、缺口上站着「守路怪」——不打掉就到不了下一带、更上不了楼；**1F~21F 全部「不打怪不能上楼」**，全塔 38 道闸墙缺口都是图论割点、77 只几何必打怪。支路凹室三面砌墙、入口也有守护怪，里面的宝石 / 血瓶 / 金币要清掉它才拿得到；第一带固定投放成长道具与三色钥匙，保证开局先捡补给再清怪。正常节奏是**杀完一层的怪、整理好补给再进下一层**，而不是直冲楼梯。怪数 5~6→9，但 21 层 `targetLoss` 与 v0.14 逐层完全一致，只是战斗场次变多、每场更轻；强敌宝库仍是纯支线（不挡上楼）。空地占比 44.4%→**40.0%**（21F 61%→36%）。
- **小精灵 / 能量核心 / 能量护盾（v0.16 引入，v0.18 重排为软门槛）**：**1F** 出生点正下方 `(1,2)` 站着常驻「塔灵小精灵 `e`」，走到旁边交互可听塔的背景故事；全塔唯一的「能量核心 `C`」在 **17F 商人房**（与商人 `N` 同房，v0.18 由 13F 后移），13F treasure 房只留盗贼任务的「锁匠工具 `j`」。**15F 起（盗贼撬开 16F 封印后）常规怪罩上「能量护盾」**（`hp×1.2 / 攻×1.04 / 防×1.0`；精英 `X` 与魔王不叠加），打得动但每场更疼 —— 这是**软门槛**：不灌顶不会被护盾硬拦住，但 v0.20 难度上调后一路躺平扛不到塔顶，得把金币 / 经验花在刀刃上、并挑准时机回来灌顶。带回核心找 1F 小精灵灌顶则按**灌顶那一刻的当前攻 / 防 / 血各 +40%**（`Math.round(当前值×1.4)`），同时上层护盾散去、怪物回到基线；什么时候回来由玩家定 —— 立刻回来早点解除吃力状态、少流血，再往上成长几层回来基数更大、这一下涨得更多，代价是路上多吃苦。怪数 **9→12**、`targetLoss` 全塔上调约 **30%**（24/26…72 → 31/34…94）；四处强敌宝库与魔王同步校准（魔王 `ATK 300→380`）。小精灵三态（讲背景 / 持核心灌顶 / 已灌顶闲聊），攻略回放会真实走出「17F 拿核心 → 逐层下楼回 1F 灌顶 → 再上楼」的往返。
- **交互等待（v0.16）**：点击远处实体时，自动寻路走到实体相邻格后不再同拍立即结算，而是**等一拍 `AUTO_STEP_MS=150`**（与自动行走移动一格同源）再交互，能看见英雄先在旁边站稳；本来就停在旁边的点击走 `walkTo()` 相邻分支仍**立即交互**。剧情打断 / 重开 / 改点别的格子由 `stopAuto()` 统一取消残留延迟。
- **怪物防御体系 / 高防低攻挡路怪（v0.17）**：用户反馈「怪防太低没有挑战性，原版魔塔怪防常接近攻击力，有些怪甚至防御超高、攻击较低，用来挡住玩家前进」。字面「怪防≈怪攻」经离线模拟会 21 层全部破不了防（怪攻本就按玩家 DEF 建模、必然大于玩家攻），故按「**怪防 = 0.65 × 每层首次战斗实测玩家攻击**」建模：每击伤害变薄、战斗从 3 回合拉到 **5 回合**，1F 裸装连史莱姆都破不了防，必须先捡第一带铁剑 / 红宝石垫攻击再回头清怪；图鉴「临界攻击」给出少挨一回合的攻击阈值。全塔总损血较 v0.16 再 **+26%**（6558→8240）。另在 **2F~16F** 每层第一道闸墙缺口与第一个凹室入口复用「石头人 `m6`」摆出 `hpW1.0 / atkW0.92 / defW1.23` 的**高防低攻挡路怪**（防 ≈ 0.80×玩家攻击、每击只剩 0.20×攻击、约 7~8 回合，攻击低但砍不动），全塔 40 只、其中 20 只落在主路真割点；1F 与 17F 及以后不投放，避免裸属性 / 屏障倍率叠加成死局。逻辑层 / 存档 / 交互 / 精灵主线零改动，纯配置层数值。
- **任务顺序重排与任务关联剧情链（v0.18）**：原四条 NPC 线是平行孤岛，v0.18 把盗贼线与精灵线接成一条因果主线：**8F 法师**认得 16F 符文是「塔灵的锁」→ **12F 老者**警告封印后头压着塔灵的气 → **15F 救出盗贼**、**13F 取回锁匠工具 `j`** 交他撬开 **16F 符文封印 `Z`** → 符文一灭、上层护盾泄满，**15F 起怪物明显变强** → **17F 商人房**拿到能量核心 → 回 **1F** 找塔灵按当前属性 +40% 灌顶、护盾散去 → **19F 钱袋 `q`** 收尾盗贼线。法师 / 老者 / 盗贼 / 商人 / 精灵与 15F~19F 逐层剧情全部互文，`help.rule` 与 `core_hint` / `fairy_charge` 剧情给出「早回 / 晚回」的取舍说明。任务格落位：`1F e` / `13F j` / `15F T` / `16F Z` / `17F C+N` / `19F q` / `21F W`。
- **攻击吸血怪「噬血蝠 `9`」（v0.19）**：按玩家【开打那一刻的当前血量】的 **15%** 吸血，且这笔削血**独立于破防伤害** —— 就算防御高到它打不动你、或攻击不够破不了它的防，只要它出手就照吸不误（堆防挡不住）。只扣玩家 HP、**不回怪血**（避免「怪回血 → 回合变长 → 吸更多」正反馈死局）。反直觉的取舍是：**血量越高打它越不合算**，先把它打掉再回头捡血瓶，比先补血再开打省 `k×15%×Δ` HP（12F 普通怪实测 HP1000 损 300 / HP4000 损 1200，精确 4 倍）；图鉴与战斗预览把这笔损血算进总损血并标「（吸血）」，战斗日志标「吸血 N」。前期 **1F~11F** 的噬血蝠经 `eliteBefore` / `eliteShift` 套超前 9 层强度，是「破不了防」的精英、**不挡上楼主路**（投放时做 BFS 非割点校验），等攻防血涨上来再回头打；**12F 起回落到常规怪池**成为后期普通怪。同期难度提高：常规怪 `lossGain 1.3→1.5`（+15%）、守门石头人 `m6 hpW 1.0→1.5`（大幅加厚、只抬 HP 不碰 DEF 死局线）、4 处宝库守卫 `m9 hpW 0.8→1.0`；血瓶同步 ×2 校准 HP 供给（小 50→100 / 大 200→400）。吸血率 15% 的硬边界是 `k×r<1 → k≤6`，故吸血**绝不能挂给长回合高防怪**（石头人 k 最大 18、骷髅兵 10）。
- **前期防杀抑制 / 难度曲线再次调高（v0.20）**：用户反馈「前期玩家应该很难出现防杀」。根因是 `build_floor_scale` 的怪 ATK 用 `ACT_D[f]`（玩家**进层** DEF）建模，但玩家按「先扫光资源再清怪」推进会在**本层内**捡铁盾把 DEF 顶高 +3~20，直接越过怪 ATK 造成 `monPerHit=0` 的零损血刷怪（首次推进 1F~11F 常规怪 30% 战斗零伤，2F/4F/5F/6F 高达 80~91%）。v0.20 新增 `DEF_GROWTH`（每层实测层内 DEF 成长）与 `ANTI_BLOCK_K=1.5`，把前 11 组 `FLOOR_SCALE.atk` 抬到「玩家清怪时的 DEF」再上浮 50%，让净伤回到设计值并加码 —— 前期零伤 **30%→0%**、前期累计损血 **+61%**；2F 就算捡到铁盾（DEF46）打史莱姆 / 蝙蝠 / 石头人仍分别要掉 24 / 45 / 70 HP。抬升作为 `build_floor_scale` 的**返回后处理**，不进循环内前缀钳制链（否则会传播到 12F 以后、把守门怪 9~17 回合净伤放大成 lethal 死局）。血瓶 / 守门怪 / 逻辑层 / 吸血怪 / 任务链全部不动。**口径澄清**：用户明确「没有说过完全不强化也能通关，需要合理利用手上的金币和经验才能通关」，故验收改为 **4 条正常强化时机路径（立刻 / 延后 18F / 19F / 20F）全通关**，`noCharge` 不再保证通关；帮助文案同步删去「不强化也能硬扛到塔顶」的旧表述。
- **战斗公式**：经典先手制，`回合数 = ceil(敌HP / (我攻-敌防))`，承受 `回合数-1` 次反击；法师系 `pierce` 无视防御；怪物手册给出「临界攻击」与「每 +1 防少掉多少 HP」。v0.19 起吸血怪 `9` 另按【开打时当前 HP】的 15% **独立扣血**，不受破防与防御影响。
- **逐层数值曲线（v0.17 重构）**：每层独立 `FLOOR_SCALE`（21 组逐层 + 9 组线性外推，共 30 组），由 `make_levels.py` 按「每层首次战斗实测 ATK/DEF」反解 —— **怪防 = 0.65 × 实测玩家攻击**、战斗拉长到 **5 回合**、每怪损血按 `costMul=5.0` 标定后再 ×1.3；v0.20 起前 11 组怪 ATK 按层内 DEF 成长补偿（前期局部微调、12F 起恢复单调爬坡），15F 起再叠护盾倍率（v0.18 收敛为 `hp×1.2 / 攻×1.04 / 防×1.0`，未灌顶期间才叠加、灌顶后散去），保证 21/21 层都有掉血压力。**怪防不再是攻击力的零头**：1F 裸装连史莱姆都破不了防，必须先捡第一带的铁剑 / 红宝石把攻击垫过破防临界；图鉴「临界攻击」会告诉还要堆多少攻才能少挨一回合。外推段专供强敌 `scaleShift` 取「超前层」数值，不会退化成当层就能打。
- **收集**：三色钥匙、血瓶、宝石、飞行器、炸弹、怪物图鉴（含每层清剿标注）、NPC 房间事件。

## 开发

```
cd mota-lite-web

python3 tools/make_levels.py        # 重新生成 levels/levels.json（改关卡后跑）
python3 tools/build_tables.py       # levels.json -> tables.js；--check 只校验一致性
python3 tools/gen_assets.py         # 重新生成图集 / 音频 / manifest.json（改美术后跑）

node tools/validate_version.mjs     # 版本 / 布局 / 字号 / 静态防漂移断言（149 项）
node tools/validate_levels.mjs      # 关卡语义断言（129 项）
node tools/validate_logic.mjs       # 逻辑层断言（482 项）
node tools/validate_assets.mjs      # 资源断言（107 项）
node tools/browser_check.mjs        # 真实 Chromium 回归（410 项，需先起 http.server 8765）
```

全套合计 **1277 项断言**（离线四套 867 + 真实浏览器回归 410；含 23 项 v0.20 专项断言）。

改完**必须递增版本号**，否则标题 / 页脚 / 版本记录会漂移：

1. `mota-lite-web/version.js` 的 `VERSION`（唯一真源，HTML 不硬编码任何版本号）
2. 同文件 `CHANGELOG` 最前面补一条，`v` 必须与 `VERSION` 完全一致

> `assets/manifest.json` 的 `version` 由 `tools/gen_assets.py` 从 `version.js` 读取并写入，升级版本后重跑该脚本即可（精灵内容确定时二进制不变）。

### 协作流程

> 完整的协作与开发约定（沟通、方案确认、版本与生成链、测试分级、备份口令、工程边界）见 **[开发注意事项.md](开发注意事项.md)**；本段只列速查项。

这个目录同时是云电脑上的工作副本，**动手前先同步远端**。仓库已配置 `pull.rebase=true` 与 `rebase.autoStash=true`，有未提交改动时也能直接拉：

```
git pull --rebase        # 或简写 git sync（已设别名）
```

日常顺序：

1. `git pull --rebase` 拉到最新
2. 改 `mota-lite-web/` 下的代码，递增 `version.js`
3. 按《开发注意事项》第 4 节做**对应量级**的校验：日常小改动只做轻量校验（语法检查 + 改动点定向验证），大功能更新或用户明确说「完整测试」才跑离线四套 + `node tools/browser_check.mjs`
4. **只有用户明确说「备份」才执行 `git add -A && git commit -m "..." && git push`**。日常代码改动、版本递增、文档更新都只留在本地，不用每次对话之后都提交；备份前默认也只做轻量校验。

### 版本控制约定

`.gitignore` 只排除「能重新生成或与运行无关」的东西，工程本身（含图集、音频、文档、截图）全部入库：

| 排除项 | 原因 |
|---|---|
| `node_modules/`、`__pycache__/`、`*.pyc` | 依赖与 Python 运行缓存 |
| `mota-lite/dist/`、`dist/` | 快应用构建产物，可重新打出 |
| `.codebuddy/`、`.cloudstudio` | 云开发平台目录 |
| `.vscode/`、`.idea/`、`.DS_Store`、`Thumbs.db` | 编辑器与系统文件 |
| `*.log` | 临时日志 |

`mota-lite-web/tools/_bak/`（v7 / v11 / v12 / v13 的关卡与 tables 备份）**保留在仓库里**：它们是回归对照与回滚依据。
